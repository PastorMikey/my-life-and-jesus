# My Life and Jesus — Online Reader

This package turns the supplied EPUB into a browser-based reader. It keeps the original EPUB page layout, images, fonts, CSS, JavaScript, galleries, and external links, while adding a mobile-friendly reader shell with Previous/Next navigation and a page selector.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a **new public repository**. A suggested name is `my-life-and-jesus`.
3. Upload **everything inside this folder** to the repository (including `index.html` and the `book` folder).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and the `/ (root)` folder, then Save.
7. GitHub will give you a public Pages address, normally like:
   `https://YOUR-GITHUB-USERNAME.github.io/my-life-and-jesus/`

Use that single address on Facebook, Instagram, X, YouTube, Rumble, email, and text messages.

## Important

The original EPUB file is intentionally **not** included in this web package. The public site contains the web-readable book assets, so readers are taken straight into the online reader instead of being given an EPUB download link.

The source EPUB remains separate in your possession.
